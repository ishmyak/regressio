# regressio

Ранний прототип Telegram-бота — персонального помощника на PHP.
Получает сообщения через webhook и отвечает на команды с помощью Telegram Bot API
и внешних информационных сервисов.

## Что есть в коде

| Команда или кнопка | Назначение |
| --- | --- |
| `/start`, `/start_kbrd` | Показать клавиатуру разделов |
| `/stop_kbrd`, «Убрать клавиатуру» | Скрыть клавиатуру |
| `/news`, «Новости» | Новости Томска из RSS |
| `/weather`, «Погода» | Прогноз погоды для Томска |
| `/currency`, «Курс валют» | Курсы доллара и евро из данных ЦБ РФ |
| `/bash`, «Баш» | Ссылка на сервис цитат |
| `/horoscope`, «Гороскоп» | Выбор знака зодиака и гороскоп |
| «Праздники» | Список праздников из RSS |
| «Анекдот», «Афоризм», «Демотиватор» | Развлекательные материалы из внешних источников |

Неизвестный текст отправляется пользователю обратно.

## Статус и ограничения

Это исторический прототип, требующий доработки перед публичным развёртыванием.
Наличие команды в коде не означает, что соответствующий внешний сервис
работает сейчас: сетевые источники не проверялись при оформлении README.

- Нет проверки подлинности webhook, полноценной обработки ошибок и тайм-аутов.
- В нескольких cURL-вызовах отключена проверка TLS-сертификата; перед
  эксплуатацией её необходимо включить и настроить доверенные сертификаты.
- Обработчик рассчитан на текстовые сообщения и напрямую обращается к полям
  входящего JSON; другие типы обновлений требуют отдельной обработки.
- В функции гороскопа используются некавыченные строковые значения,
  несовместимые с PHP 8 без исправления.
- Получение демотиваторов отмечено в исходнике как неработающее.
- Некоторые источники используют HTTP и зависят от устаревшего формата ответа.

## Устройство проекта

- `personalhelper-bot-functions.php` — webhook и функции обработки команд.
- `composer.json` — пустой манифест; сторонние Composer-пакеты не объявлены.
- `_config.yml` — тема GitHub Pages, к запуску бота не относится.

Для доработки нужны PHP с расширениями cURL и SimpleXML,
доступ к внешним HTTP/HTTPS-источникам и HTTPS-сервер для webhook.
Вызовы `file_get_contents` по URL требуют `allow_url_fopen`.
Автоматизированных тестов и подтверждённой конфигурации развёртывания нет.

## Учётные данные

Ранее в истории репозитория был опубликован токен бота. Его необходимо
отозвать через BotFather и выпустить новый: удаление строки из текущего
файла не удаляет токен из истории Git.
Не используйте старый токен и не добавляйте реальные секреты в репозиторий.

Текущий код читает токен из переменной окружения `TELEGRAM_BOT_TOKEN`.
При её отсутствии возвращает HTTP 503, не обращаясь к API Telegram.
Передайте новый токен через защищённые настройки окружения PHP-процесса
или хостинга; загрузка `.env`-файлов в этом проекте не реализована.

Пересылка входящих сообщений администратору по умолчанию отключена.
Для её явного включения можно задать `TELEGRAM_ADMIN_CHAT_ID` в окружении
PHP-процесса. В этом режиме администратору передаются текст, имя и ID чата
пользователя; не включайте его без необходимости и уведомления пользователей.
